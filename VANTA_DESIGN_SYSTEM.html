11 — Animations

/* Utiliser uniquement ces 3 animations */ /* Apparition standard — menus, panels, items */ @keyframes v-fadeIn { from { opacity: 0; transform: translateY(8px); } to { opacity: 1; transform: translateY(0); } } /* Modals, popups */ @keyframes v-scaleIn { from { opacity: 0; transform: scale(0.95); } to { opacity: 1; transform: scale(1); } } /* Slide latéral — listes, sidebar */ @keyframes v-slideRight { from { opacity: 0; transform: translateX(-12px); } to { opacity: 1; transform: translateX(0); } } /* Transition par défaut pour hover/focus */ transition: all 0.2s cubic-bezier(0.25, 0.1, 0.25, 1); /* Toggle knob spring */ transition: transform 0.2s cubic-bezier(0.34, 1.56, 0.64, 1);

PAS de : bounce, scale pulse, glow pulse, infinite spin, shake.
PAS de : backdrop-filter (cassé dans FiveM CEF).
Durée max : 0.3s. Tout doit être instantané et responsive.

12 — Rules

DO
Font Inter partout
Fond noir pur (#000 ou #0a0a0a)
Texte blanc, hiérarchie via opacity
Bordures subtiles rgba(255,255,255,0.06-0.15)
Séparation par espacement, pas par lignes
Radius 6-14px (Apple-style)
Animations CSS courtes (0.15-0.3s)
Items 1:1 aspect ratio en grille
Couleur de rareté = bordure uniquement
Monochrome. Silver comme accent brand.
DON'T
Grunge, rouille, poussière, néon
Glassmorphism / backdrop-filter blur
Drop shadows (utiliser bordures)
Gradients sur les fonds
Bounce, scale, glow, pulse
confirm() ou prompt() (freeze FiveM)
HTML5 drag (cassé dans FiveM CEF)
Couleurs saturées en fond (rareté = bordure)
Plus de 2 couleurs par écran
Radius > 20px (sauf pills/toggles)
